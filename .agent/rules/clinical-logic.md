# Clinical Logic & "Speed Play" Rules
# Version: 1.0.0

## 1. HOME SLEEP TEST (HST) — CPT 95800
### Inclusion Criteria:
- BMI > 30 (Obesity)
- Chronic Snoring
- Daytime Sleepiness (Epworth > 10)
### Exclusion (12-Month Lookback):
- Suppression is active if any HST or Polysomnography has been pended in the last 365 days.

## 2. EEG — CPT 95816
### Inclusion Criteria:
- Suspected Seizures
- Syncope or Unexplained LOC
- Chronic Migraines (with aura)
### Exclusion (12-Month Lookback):
- Suppression active if CPT 95816 or 95819 ordered in last 365 days.

## 3. ALLERGY PANEL
### Inclusion Criteria:
- Chronic Rhinitis (> 6 months)
- Persistent Asthma
### Exclusion:
- Suppression if panel run in last 12 months.
